# Mail Server Roadmap

## Current Stack

- **Mail Server:** Stalwart Mail Server (Rust, self-hosted)
- **Protocols:** SMTP, IMAP, POP3, JMAP, CalDAV, CardDAV, ManageSieve
- **Admin UI:** Built-in Stalwart web admin (port 443/8080)
- **Storage:** RocksDB (default), pluggable backends

### DNS Records (Per Domain)

- [ ] DKIM TXT record (per selector, generated by Stalwart)
- [ ] DMARC TXT record (`v=DMARC1; p=quarantine; rua=mailto:postmaster@<domain>`)

  if envelope :is "to" "oz@naka.sh" {

### Gmail "Send As" Configuration

For each address (`oz@oznakash.com` and `oz@naka.sh`):

1. Gmail > Settings > Accounts and Import > Send mail as > Add another email address
2. Enter name and email, check "Treat as alias"
3. SMTP Server: your mail server hostname
4. Port: 587 (STARTTLS) or 465 (SSL/TLS)
5. Username: the full email address
6. Password: the Stalwart account password
7. Confirm via verification email

## Phase 2: Snappymail Webmail Integration

### Goal

Give users a web-based interface to read/send email and manage their own forwarding rules (Sieve filters) without admin intervention.

### Architecture

```
                    ┌──────────────────────────────────┐
                    │           Mail Server             │
                    │                                   │
  Users ──────────► │  :443  Stalwart (admin/JMAP)      │
                    │  :25   SMTP inbound               │
                    │  :587  SMTP submission             │
                    │  :993  IMAPS                       │
                    │  :4190 ManageSieve                 │
                    │                                   │
  Users ──────────► │  :8443 Snappymail (webmail)       │
                    │         │                         │
                    │         ├──► IMAP  (localhost:143) │
                    │         ├──► SMTP  (localhost:587) │
                    │         └──► Sieve (localhost:4190)│
                    └──────────────────────────────────┘
```

### Tasks

- [ ] Create `docker-compose.yml` with stalwart + snappymail services
- [ ] Pre-configure Snappymail default domain (auto-connect to Stalwart IMAP/SMTP/ManageSieve)
- [ ] Enable ManageSieve plugin in Snappymail (Sieve filter UI for users)
- [ ] Configure TLS for Snappymail (reuse ACME certs or reverse proxy)
- [ ] Create `.env.example` with required environment variables
- [ ] Test: user login, send/receive, create forwarding filter via Sieve UI

### Snappymail ↔ Stalwart Integration

| Snappymail Feature | Stalwart Protocol | Port |
|--------------------|-------------------|------|
| Read/send email | IMAP + SMTP | 143, 587 |
| Manage filters & forwarding | ManageSieve | 4190 |
| User authentication | IMAP login | 143 |
| Contacts (optional) | CardDAV | 443 |

### User Experience

1. User navigates to `https://webmail.<domain>:8443`
2. Logs in with their email + password
3. Reads and sends email via the web UI
4. Goes to Settings > Filters to create/edit Sieve rules (forwarding, sorting, etc.)
